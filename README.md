# Netcradus UK | React + Vite

Netcradus UK web application built with React 19, Vite 8, and Tailwind/Vanilla CSS design system.

## Deployment to GitHub Pages

This project automatically deploys to GitHub Pages via GitHub Actions workflow (`.github/workflows/deploy.yml`).

### Local Development
```bash
npm install
npm run dev
```

### Build & Deploy
```bash
npm run build
npm run deploy
```
